# MiLaboratories

> MiLaboratories builds best-in-class software for immunological and genomic data analysis. Its flagship MiXCR is the gold-standard command-line analyzer for T-cell receptor (TCR) and immunoglobulin (IG/antibody) repertoire sequencing, and Platforma.bio is a UI-first, no-code computational-biology platform whose blocks are built with the TypeScript Platforma SDK over the Platform API. This file is generated by the API Evangelist enrichment pipeline from the catalog and repo artifacts; it is not published by the provider.

## Products
- [MiXCR](https://mixcr.com/): Command-line NGS immune-repertoire analyzer (TCR/BCR profiling).
- [Platforma.bio](https://platforma.bio/): UI-first no-code computational-biology platform for NGS data.
- [Platforma SDK](https://docs.platforma.bio/sdk/): TypeScript SDK for building interactive Platforma blocks.
